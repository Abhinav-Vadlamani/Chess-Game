# CBurnett chess pieces

These PNGs are 256px rasterizations of the CBurnett SVG piece set from the
[Lichess source repository](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).
They are bundled here so the Pygame renderer can use crisp, consistent sprites
without relying on system Unicode fonts. Preserve the upstream asset licensing
and attribution when redistributing this project.
